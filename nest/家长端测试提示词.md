# 家长端（nest-parent-portal）测试提示词

> 用途：作为自动化测试 Agent 或人工 QA 的测试指令。覆盖家长端所有核心交互链路，
> 既验证界面可用性，也验证其与后端（`admin/server`）接口的交互正确性。
> 测试结论应区分「已通过 / 已修复 / 待人工」三类。

## 角色与目标

你是一名 QA 工程师，负责测试「宠物花园」家长端（仓库 `nest/` 目录下的 Vue 3 单页应用）。
家长端是家长用手机查看孩子宠物成长、给孩子加减分、领养宠物的通道，所有数据通过
`/api`（兼容 `/pet-garden/api`）调用后端。请按下面的用例逐项测试，发现的问题尽量直接修复
（前端在 `nest/src`，后端在 `admin/server/routes/parent.js` 与 `public.js`），无法修复的标记为待人工。

## 前置条件（每次测试前准备）

1. 启动后端：`cd admin/server && node index.js`（默认端口 3002，演示数据会自动播种）。
   确认 `GET /api/health` 返回 `{"status":"ok"}`。
2. 启动家长端：
   - 开发模式：`cd nest && npm install && npm run dev`（默认 5173，Vite 已代理 `/api` → 3002）。
   - 或生产模式：先 `npm run build`，再用任意静态服务器托管 `dist/` 并把 `/api` 代理到 3002
     （参考 `nest/README.md` 的 Nginx 配置）。
3. 准备一个测试用学生：
   - 进入教师端（`admin`）注册教师 → 建班级 → 添加学生，记下该学生的分享链接
     `http://<host>/student/<studentId>`；
   - 或直接用演示班级 `向日葵班 · 成长花园` 下的学生（需先确认其家长密码状态）。
4. 浏览器开隐身窗口，避免 localStorage 中残留登录态干扰。

## 测试用例

### A. 排行榜（首页 `/`）
- A1 打开首页，应显示班级切换器与班级排行榜。
- A2 切换班级，列表按积分降序刷新，排名、姓名、等级、积分正确显示。
- A3 点击某学生行，跳转至 `/student/<studentId>` 详情页。

### B. 学生详情 / 宠物（公开）
- B1 未登录打开分享链接，应展示学生姓名、学号、总积分、宠物状态（有/无宠物）与最近记录。
- B2 未领养宠物时显示「🥚 还没有领养宠物」与「领取宠物」按钮（需家长登录后可见）。
- B3 已领养宠物时显示宠物、成长进度条与「距离下一级还需 X 成长值 / 已满级」。

### C. 家长登录 / 首次设置密码
- C1 点击「家长登录」→ 弹窗默认「家长登录」模式，输入密码（≥4 位）登录。
- C2 若该学生尚未设置家长密码，登录应失败并自动切换到「首次设置家长密码」，
  展示验证码「a × b = ?」；输入正确计算结果后设置密码并登录成功。
- C3 验证码答案错误时提示「验证码错误，请重新计算」，且可重新输入（验证码为无状态，
  同一题目可重试）。
- C4 已设置密码后再次走 setup 接口应被拒绝（409）。
- C5 错误密码登录返回 401。

### D. 领养宠物
- D1 登录后（且为本人学生）点击「领取宠物」，弹出宠物选择页，选择一个普通宠物确认领养成功。
- D2 神兽（白老虎/独角兽/青龙）领养**受班级 VIP 限制（代码逻辑保留）**；因后续所有班级都会设为 VIP，实际均可领养。
  - D2a 将班级设为 VIP（存在有效 `class_vip_subscriptions` 记录）后，家长领养神兽应成功（200）。
  - D2b 班级未开通 VIP 时，领养神兽应被后端拒绝（返回 400 并提示「神兽伙伴需开通 VIP 后才能领养」），前端给出明确错误提示。

### E. 加分 / 减分
- E0 规则来源：家长端加减分按钮应**同时包含全局规则与本班教师自定义规则**。验证：在教师端为该班新建一条自定义规则（如「主动帮助同学 +5」），家长端登录后该规则应出现在按钮列表中（按班级隔离，不会串到别的班）。
- E1 登录后「家长操作区」展示按分类分组的加减分按钮。
- E2 点击某规则，对应学生积分/成长值变化，记录列表刷新。
- E3 触发冷却（若后端有按规则冷却）时给出友好提示，而非崩溃。

### F. 修改密码
- F1 点击「修改密码」→ 输入原密码与新密码（≥4 位）→ 确认修改成功。
- F2 原密码错误时提示失败；改密后用新密码可登录、旧密码不可登录。

### G. 登出
- G1 点击「登出」后清除本地登录态，操作区与领养按钮按未登录态呈现。
- G2 当当前登录的是「另一名学生家长」时，详情页应给出提示并提供登出入口。

### H. 教师端重置家长密码后的恢复
- H1 教师端（管理端学生详情 → 重置家长密码）清空该学生家长密码后，
  家长再次登录应返回 `NO_PASSWORD_SET` 并引导重新设置密码（走 C2 流程）。
- H2 重新设置密码后可正常登录、领养、加分。

### I. 异常与边界
- I1 打开不存在的学生链接（`/student/<fakeId>`）应显示「学生不存在」而非白屏。
- I2 网络/接口异常时各操作应有错误提示且不崩溃。
- I3 接口限流（登录/注册有频率限制）触发时给出可读提示。

## 验收标准

- 上述用例全部通过或已修复；
- `cd nest && npm run build` 通过（无 TypeScript / 构建错误）；
- 发现的阻断性问题已修复并复测通过；
- 无法在当前环境修复的问题（如需要真实手机号/第三方支付、需要可视化浏览器回归）明确列出交人工。

## 已知限制（当前版本）

- 完整可视化浏览器回归（像素级 UI、移动端真机）建议由人工或 CI 中的 Playwright 完成。
